Исправление фавикона для мобильных устройств:

1. Скриптом PIL из текущей app-icon.png (256×256, прозрачный фон) сгенерировать в static/compositor/:
   - favicon-32.png (32×32) — для вкладок/закладок;
   - favicon-192.png и favicon-512.png — для Android (требования манифеста);
   - apple-touch-icon.png (180×180) — логотип на НЕПРОЗРАЧНОМ белом фоне, чтобы iOS не заливал его чёрным.

2. Создать site.webmanifest в корне: name «SCU», иконки 192/512, theme_color/background_color #ffffff.

3. Обновить <head> в index.html и privacy.html:
   - <link rel="icon" type="image/png" sizes="32x32" href="/static/compositor/favicon-32.png">
   - <link rel="icon" type="image/png" sizes="192x192" href="/static/compositor/favicon-192.png">
   - <link rel="apple-touch-icon" sizes="180x180" href="/static/compositor/apple-touch-icon.png">
   - <link rel="manifest" href="/site.webmanifest">
   - <meta name="theme-color" content="#ffffff"> (цвет интерфейса мобильного браузера)
   - абсолютные пути с «/» вместо относительных.

4. В ответе пояснить пользователю: во вкладках мобильных браузеров фавикон не отображается ни у кого (ограничение платформы) — проверять нужно через «Добавить на главный экран» или закладки; после правок иконка на главном экране будет корректной и на Android, и на iOS.

Старые ссылки (app-icon.png как favicon) заменяются; сам файл app-icon.png остаётся — он используется в футере.
