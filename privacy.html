Политика конфиденциальности

Обновлено: 30.09.2026

Эта политика честно описывает, что происходит с данными, когда вы открываете сайт SCU и пользуетесь им. Коротко: сайт не знает о вас почти ничего, и это не преувеличение.

Что собирается

При открытии страницы и при нажатии кнопки «Скачать» сервер получает технические данные вашего запроса: IP-адрес и строку User-Agent (их передаёт любой браузер при любом запросе к любому сайту). Дальше происходит следующее:

  • из IP-адреса и User-Agent вычисляется односторонний хеш SHA256(соль + IP + User-Agent);
  • сохраняется только этот хеш и время создания — в виде маркера в хранилище Vercel Blob;
  • сырой IP-адрес и User-Agent нигде не записываются — ни в логи сайта, ни в базу, ни куда-либо ещё.

Хеш нужен ровно для одного: посчитать уникальных посетителей и уникальные загрузки, чтобы в шапке сайта отображались счётчики. Один и тот же пользователь добавляет в счётчик ровно единицу, сколько бы раз он ни заходил.

Что НЕ собирается

  • Никаких cookies, localStorage, sessionStorage.
  • Никакой аналитики (Google Analytics, Яндекс.Метрика и подобные не подключены).
  • Никакой рекламы и трекинговых пикселей.
  • Никаких имён, почт, телефонов, аккаунтов и форм ввода — на сайте нет ни одной формы.
  • Никакой информации о вашей системе, экране, локации или поведении.

Можно ли по хешу вас опознать

Нет. Хеш необратим: из него нельзя восстановить IP-адрес или User-Agent. Теоретически хеш можно «перебрать», если перебрать все возможные комбинации IP и User-Agent, но это непрактично, а соль хеширования известна только серверу. Связать маркер в хранилище с конкретным человеком сайт не может — этим занимается не политика, а математика.

Сторонние сервисы

  • Vercel Inc. — хостинг сайта и API. При любом обращении к сайту Vercel технически обрабатывает ваш запрос (IP, время, URL) согласно своей политике конфиденциальности. Управлять этим сайт не может.
  • Google Fonts — шрифты загружаются с серверов Google, поэтому Google видит ваши запросы к ним (IP-адрес). Это стандартная механика подключения веб-шрифтов.
  • GitHub — по кнопкам «Скачать» и «Исходный код» вы переходите на github.com: кнопка «Скачать» ведёт прямо на файл установщика в GitHub Releases, сам файл лежит на GitHub, а не на сайте. GitHub получает данные вашего визита согласно своей политике; сайт при этом фиксирует только факт нажатия «Скачать» (см. раздел «Что собирается»).
  • VirusTotal — на главной есть бейдж с результатом сканирования сборки. Сама картинка хранится на сайте и никуда не отправляется; по клику вы переходите на virustotal.com, который далее обрабатывает ваш визит по своей политике конфиденциальности.
  • Ozon Банк — блок «Поддержи проект» (ссылка и QR-код) ведёт на страницу оплаты СБП Ozon. Всё, что вы вводите там, обрабатывается Ozon Банком по его правилам; сайт этих данных не видит и не получает.

Срок хранения

Маркеры-хеши хранятся бессрочно — они и есть накопленные счётчики. Удаление отдельных маркеров технически невозможно, потому что по хешу нельзя определить, чей он именно.

Данные приложения

Само приложение SCU — отдельная программа, работающая локально на вашем компьютере. Настоящая политика описывает только сайт. Что делает с данными установленное приложение, описано в его документации и исходном коде: github.com/endlessbum/SCU.
